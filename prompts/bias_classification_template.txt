#
# Used to produce the cognitive bias labels in bias_labels/*_bias_labels_*.json
# and bias_labels/*_shared_failure_bias_*.json. Two classifiers ran this
# prompt independently: Llama-3.3-70B-Instruct-Turbo and GPT-4o-mini. Cohen's
# kappa on the per-question labels appears in Table V of the paper.
#
# Inference parameters: max_tokens=10, temperature=0.0. Output is parsed by
# scanning for one of the five labels {AVAILABILITY_BIAS, ANCHORING_BIAS,

#
# Placeholders are filled with the question stem, full option block (one line
# per option, formatted as "A: text"), the gold letter and its option text,
# and the wrong letter chosen unanimously by the strong model ensemble and
# its option text.

- ANCHORING_BIAS (over-relying on first piece of information)
- FRAMING_EFFECT (different conclusion from same info presented differently)
- PREMATURE_CLOSURE (stopping reasoning too early)
